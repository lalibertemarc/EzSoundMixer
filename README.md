# EzSoundMixer

Sound volume sliders and presets for WoW Forever, without digging through the options menu.

Inspired by Twitch streamer Payo and his Zenewin Zenehon and flute moments. PPC my little man

## Usage

- Click the minimap button (or use the addon menu on the minimap, or type `/ezsm`) to open the panel.
- Right-click the minimap button to switch presets without opening the panel. Drag it to move it around the minimap; `/ezsm minimap` hides or shows it.
- Drag the sliders or tick the checkboxes; changes apply immediately and match the game's Audio options.
- **Save** stores the current volumes as a named preset. Pick presets from the dropdown; **Delete** removes the selected one.
- `/ezsm <preset name>` applies a preset directly, e.g. a macro with `/ezsm Quiet`.

Presets are shared by all your characters.

## Install

Copy the `EzSoundMixer` folder into `World of Warcraft\_classic_beta_\Interface\AddOns`.
